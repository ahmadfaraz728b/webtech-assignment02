## What it does
Slide Maker turns plain text into slides. You type in one box and the preview updates as you type.

## Features
1. Split slides using `---`
2. Headings with `#`, `##`, `###`
3. Previous / Next buttons with a page counter (e.g. 1 / 3)
4. Store button saves your text using localStorage
5. Show button opens a full screen presentation
6. Keyboard: `Ctrl + S` saves, arrow keys change slides

## Built With
HTML, CSS and plain JavaScript (no libraries).

## How to Open
Put `index.html`, `style.css` and `script.js` together in one folder, then open `index.html` in your browser.
